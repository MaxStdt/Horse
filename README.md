# Маршруты коня

Программа на Python, которая считает количество маршрутов шахматного коня из левого верхнего угла прямоугольной доски N×M в правый нижний. Конь может ходить только на 2 клетки вниз и 1 клетку вправо или на 1 клетку вниз и 2 клетки вправо. Путь нулевой длины (когда старт совпадает с финишем, N=M=1) считается корректным маршрутом и даёт ответ 1.

## Требования

- Python 3.8+
- VS Code (рекомендуется) с расширением `ms-python.python`

## Формат входных и выходных данных

Входной файл содержит два натуральных числа N и M (1 ≤ N, M ≤ 50), разделённых пробелом или переводом строки. Выходной файл содержит одно число — количество маршрутов.

## Использование

Программа принимает имена входного и выходного файлов аргументами командной строки:

```bash
python main.py <input_file> <output_file>
```

Если аргументы не переданы, используются значения по умолчанию: `input.txt` и `output.txt`.

### Примеры запуска

Проверка первого примера:

```bash
python main.py tests/input1.txt tests/output1.txt
cat tests/output1.txt       # → 1
```

Проверка второго примера:

```bash
python main.py tests/input2.txt tests/output2.txt
cat tests/output2.txt       # → 293930
```

Запуск с файлами по умолчанию (должны лежать в корне проекта):

```bash
python main.py
# читает input.txt, пишет output.txt
```

## Как работает алгоритм

Используется динамическое программирование. Так как конь ходит только вниз и вправо, клетки обходятся сверху-вниз и слева-направо, и для каждой клетки `dp[i][j]` суммируются значения двух «родителей»:

```
dp[i][j] = dp[i-2][j-1] + dp[i-1][j-2]
```

- `dp[0][0] = 1` — пустой путь.
- Слагаемые учитываются только если индексы не выходят за границы доски.
- Ответ — `dp[N-1][M-1]`.

Временная сложность: O(N·M). Память: O(N·M).

## Отладка в VS Code

Файл `.vscode/launch.json` содержит готовые конфигурации. Аргументы (имена файлов) прописаны явно в массиве `args`:

```json
{
    "version": "0.2.0",
    "configurations": [
        {
            "name": "Python: пример 1",
            "type": "debugpy",
            "request": "launch",
            "program": "${workspaceFolder}/main.py",
            "console": "integratedTerminal",
            "cwd": "${workspaceFolder}",
            "args": ["tests/input1.txt", "tests/output1.txt"]
        },
        {
            "name": "Python: пример 2",
            "type": "debugpy",
            "request": "launch",
            "program": "${workspaceFolder}main.py",
            "console": "integratedTerminal",
            "cwd": "${workspaceFolder}",
            "args": ["tests/input2.txt", "tests/output2.txt"]
        }
    ]
}
```

**Как отлаживать:**

1. Откройте панель «Run and Debug» (`Ctrl+Shift+D`).
2. В выпадающем списке выберите нужную конфигурацию (например, «Python: пример 2»).
3. Поставьте точку останова в `main.py` (например, на строке с `dp[0][0] = 1`).
4. Нажмите `F5`.

**Важно:** не используйте `${command:pickArgs}` в `args` — из-за известной ошибки расширения Python все введённые аргументы попадут в `sys.argv[1]` одной строкой. Прописывайте аргументы явно, как показано выше.

### Виртуальное окружение

Если в проекте есть `.venv`, выберите его интерпретатор: `Ctrl+Shift+P` → **Python: Select Interpreter** → `.venv`. Ручная настройка `python.defaultInterpreterPath` в `settings.json` не требуется.
